# CleanBrain
Расширение

Гайд по активации:

1. Скачиваем расширение zip и разархивируем , либо  по ссылке (можно скопировать команду и вставить через консоль в необходимую папку ) через: git clone https://github.com/Fok-industries/CleanBrain.git  не стоит прятать папку(расширение - где оно хранится ) по неизвестному пути т.к в последствии придется обратиться к нему 
2. Нужно перейти в настройки браузера (2 способа): а) переходим по ссылке chrome://settings/ б)В верхнем правом углу браузера ( я рассматриваю гугл ) нажимаем на 3 точки ->в открывшейся панели выбираем пункт: "настройки" (они в самом низу ,перех выходом из аккаунта). Далее в меню переходим на вкладку расширения ![image](https://github.com/user-attachments/assets/2c8fed6c-1b8d-47ae-a848-e5aa3e6a41da)
3.Далее в этой вкладке в правом верхнем углу включаем режим разработчка ![image](https://github.com/user-attachments/assets/9baccb0b-7d63-4ee2-b307-584dd1a9676c) ,после чего у нас появляется необходимый функционал слева и мы должны выбрать "Загрузить распакованное расширение" ![image](https://github.com/user-attachments/assets/97f7e279-f72f-415f-9700-a596960ab3fb) Интерфейс предложит указать папку,поэтому указываем папку в котором хранится расширение (где мы распаковали расширение соответственно).
